# Projeto Elo Comum

💡 Proposta do Projeto

O Elo Comum é uma plataforma web desenvolvida para incentivar o consumo colaborativo, permitindo que pessoas compartilhem, doem, emprestem ou troquem itens dentro de uma comunidade.

A plataforma busca reduzir desperdícios, estimular a reutilização de recursos e fortalecer a colaboração entre pessoas, alinhando-se aos Objetivos de Desenvolvimento Sustentável (ODS) da ONU, especialmente:

ODS 11 – Cidades e Comunidades Sustentáveis
ODS 12 – Consumo e Produção Responsáveis
ODS 13 – Ação Contra a Mudança do Clima

O sistema permitirá que usuários publiquem itens disponíveis, encontrem produtos próximos de sua necessidade e realizem solicitações de interesse de forma simples e organizada.
